Bricklab uses models from the LDraw.org Parts Library, release 2026-08.
LDraw.org is an independent community project representing real LEGO parts.

See attribution.json for creators, exact source URLs, dependency lists and the
CC BY 2.0 / CC BY 4.0 licences applicable to each derived geometry. The original
licence documents are distributed alongside this file.

Modifications: triangulation with Three.js LDrawLoader, coordinate conversion,
vertex indexing and rounding, omission of edge lines and free recolouring.
The original LDraw source headers are retained in scripts/ldraw-sources.json.
